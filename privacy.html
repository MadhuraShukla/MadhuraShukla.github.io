Privacy policy — pune-job-tracker

Effective date: 26 September 2026.

pune-job-tracker is operated for its owner's personal job search.

Information accessed and purpose

The application reads the authorised Google account's email address to confirm the intended Drive owner. It uploads resume documents prepared on the owner's computer to Google Drive and checks metadata, checksums and permissions for its folder and files. It requests the limited drive.file scope, covering files created by the application or explicitly made available to it by the user.

The associated job tracker reads and updates an explicitly shared Google Sheet. That Sheet can contain job details, hiring-contact evidence, user-entered application statuses and notes, configuration values and resume links. This information is used to organise the owner's job search and deliver documents for review.

Storage and access

Resume documents and tracker data are stored on the owner's computer and in the owner's chosen Google Drive and Google Sheet. Local backups and workflow records may be retained. The local Drive authorisation is encrypted using the current Windows user's credential protection. The application does not store the user's Google password.

The workflow uses the owner's configured AI assistant for job review and resume preparation. Information included in that work is processed by that service under the owner's account settings and the service's terms. Google hosts the Drive and Sheets content under its own terms.

Sharing and use limits

The application does not sell Google user data, use it for advertising, or automatically send resumes to employers. It does not make uploaded resumes or the tracker publicly accessible or change sharing permissions. The owner controls any later sharing through Google Drive or Google Sheets.

Google Workspace API data is not used by this application to develop, improve or train non-personalized AI or machine-learning models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements: Google API Services User Data Policy.

Retention and user control

Files and local workflow records are retained until the owner removes them. The owner can revoke the application's Google access through Google Account settings, delete cloud files and remove local copies or backups. Revoking access prevents future authorised access; it does not itself delete existing documents or local records.

Contact and updates

For questions, use the support email displayed on the application's Google consent screen. This page will be updated if the application's data practices change.

This public website

These information pages are hosted on GitHub Pages. They do not contain resumes, job-tracker records or credentials. This website uses no application analytics, forms or advertising. GitHub may log visitors’ IP addresses for security purposes under the GitHub Privacy Statement.
